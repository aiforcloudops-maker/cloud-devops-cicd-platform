# DevSecOps & Security

## 1. Overview

Security is integrated into the Cloud DevOps CI/CD Platform as part of
the software delivery lifecycle.

The objective is to identify security issues as early as possible
before application artifacts are promoted toward deployment.

The platform follows a DevSecOps approach:

```text
Code
  ↓
Test
  ↓
Security Scan
  ↓
Build
  ↓
Container Scan
  ↓
Deploy
